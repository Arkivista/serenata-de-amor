# Backlog Priorizado

## P0 — Fundação documental e validação institucional

1. Confirmar documentos de exemplo anonimizados.
2. Validar escopo do MVP com arquivistas.
3. Validar regras mínimas e comentários padronizados.
4. Validar modelo conceitual e requisitos de auditoria.

## P1 — Ambiente técnico

1. Criar backend FastAPI isolado.
2. Criar frontend React/Vite isolado.
3. Configurar PostgreSQL, Docker Compose e `.env.example`.
4. Configurar testes, lint e formatação.
5. Criar migrações iniciais.

## P2 — Tabela de temporalidade

1. Upload e hash.
2. Detecção de camada de texto.
3. Protótipo isolado de extração por modelo real.
4. Revisão manual.
5. Aprovação e versionamento.
6. Exportação CSV/XLSX.

## P3 — LED

1. Upload e hash.
2. Detecção de modelo padronizado.
3. Protótipo isolado de extração.
4. Revisão manual e persistência.

## P4 — Motor de regras

1. Normalização testável.
2. Catálogo de regras versionadas.
3. Execução com evidências.
4. Comentários padronizados.
5. Testes de casos conformes, divergentes e ambíguos.

## P5 — Interface e relatório

1. Tela de análise com filtros e decisões.
2. Histórico de decisões.
3. Relatório HTML.
4. Relatório PDF.

## P6 — Segurança, auditoria e evolução

1. Autenticação e autorização.
2. Políticas de retenção.
3. Preparação para PDF comentado.
4. Interface opcional para IA, somente com autorização futura.
